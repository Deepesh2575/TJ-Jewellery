# PJ Jewellery

A responsive demo storefront for PJ Jewellery, designed with a warm, editorial look and a focus on everyday fine jewellery.

## Features

- Responsive layout for desktop and mobile
- Product cards with category filters
- Interactive demo shopping bag counter
- Mobile navigation menu
- Newsletter form with an on-page confirmation
- Accessible labels and reduced-motion support

## Run locally

No build step or package installation is required. From this folder, start a local web server:

```powershell
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

Alternatively, open `index.html` directly in a browser.

## Project files

- `index.html` — storefront content and page structure
- `styles.css` — visual design and responsive styles
- `script.js` — product filtering, bag counter, menu, and newsletter interactions

## Demo notes

The shopping bag and newsletter form are front-end demonstrations only. They do not process payments, save orders, or submit email addresses to a mailing list. Product and hero photography is loaded from Unsplash, and fonts are loaded from Google Fonts, so those assets require an internet connection.
